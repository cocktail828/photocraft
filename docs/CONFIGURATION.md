# 配置与菜单

配置文件名固定为 **`PhotoCraft.conf`**，内容采用 UTF-8 TOML。源码运行、便携可执行程序、deb 与 Windows 安装版使用同一套配置代码、默认值和文件名。

| 系统 | 配置位置 |
| --- | --- |
| Linux | `$XDG_CONFIG_HOME/PhotoCraft/PhotoCraft.conf`，默认 `~/.config/PhotoCraft/PhotoCraft.conf` |
| Windows | `%APPDATA%\PhotoCraft\PhotoCraft.conf` |
| macOS 源码运行 | `~/Library/Application Support/PhotoCraft/PhotoCraft.conf` |

窗口大小、位置另存到同目录的 `state.toml`；不会混进配置导入 / 导出文件。`PHOTOCRAFT_CONFIG_DIR` 可指定另一个配置目录，适用于便携运行和测试，源码与打包程序均支持。

## 菜单

- **文件**：打开图片（Ctrl+O）、保存图片（Ctrl+S）、退出。只保存已应用的操作与压缩设置，复用完整分辨率结果；未应用压缩时沿用原格式，未编辑图片直接复用打开时的原文件字节。
- **编辑**：撤销、重做。
- **视图**：适应窗口、实际像素、放大、缩小、深色主题。
- **配置**：编辑、重新加载、导入、导出、打开目录、恢复默认配置。
- **帮助**：演示照片、配置说明、关于。

「图像压缩」位于左侧功能栏，提供格式、画质与编码设置；不限制文件大小、不自动降质。预览勾选框位于格式说明下方。输出像素始终沿用当前编辑图片的实际尺寸；证件照模板在「应用裁剪」时生成指定像素，压缩和保存不再进行模板缩放。保存入口统一在文件菜单。

「背景色」为独立的左侧功能，通过「填充颜色」选择颜色后实时预览透明区域填充，不额外展开白、蓝等快捷按钮，点击上方统一的「应用」后修改图片，支持撤销、重做。不透明区域保持原样，不提供自动抠图。裁剪页不再包含背景填充按钮。

底部固定分为「预览 / 当前」两列。预览列统一展示当前工具草稿的实际格式、尺寸、编码体积和有损状态，水印、背景色、旋转、裁剪与压缩页不再独立显示结果；当前列始终只代表会保存的已应用内容。原文件信息可悬浮文件名查看。所有需要确认的操作共用画布上方的「应用」按钮；图片增强调整即应用，画笔松开即应用。

背景色只处理透明或半透明区域。对于不透明照片，底部说明填色无效的原因，并禁用应用，避免产生空撤销步骤；若要替换照片中不透明的背景，需要先擦除对应区域。左侧「关于」按钮已替换为直接显示版本的文字，关于窗口保留在帮助菜单。

「编辑配置…」（`Ctrl+,`）提供内置 TOML 编辑器。「检查配置」只校验；「保存并应用」会先检查语法、字段、范围和重复模板名，合法后原子保存并立即应用。校验失败不覆盖文件；取消不保存。

「导入配置…」接受 TOML 内容的 `.conf` / `.toml` 文件，先校验，再替换主题、颜色和裁剪模板并立即应用。无效文件不会改变已保存配置与当前设置。

「导出配置…」默认文件名为 `PhotoCraft.conf`，保留配置文本与注释，便于备份和跨机器使用。

「重新加载配置」（`F5`）读取外部编辑后的文件并立即应用；出错时保留原先运行中的设置。

「恢复默认配置…」确认后恢复默认主题、颜色与三个裁剪模板（1 寸、2 寸、小 1 寸），可修复写坏的配置文件。配置操作不会修改照片像素、清除图片撤销记录或重置窗口位置。

## 编辑裁剪下拉框

每个 `[[crop.templates]]` 块对应一个模板，顺序就是下拉框顺序；可直接修改、重排或删除。自由裁剪、按比例裁剪始终保留。

也可在裁剪面板点击「新增模板」，在弹窗填写名称及宽、高像素。默认带入当前模板尺寸，或自由 / 按比例裁剪时的取景框尺寸；新增成功后保存到配置并选中，仅设置下一次裁剪，不会修改当前照片。同名模板需改名，取消不会写入配置。

下面的配置只显示一个模板，以及两个通用裁剪模式：

```toml
[appearance]
theme = "light" # light 或 dark

[[crop.templates]]
name = "我的报名照片"
width_px = 300
height_px = 400
background = "#ffffff"
```

只有 `name`、`width_px`、`height_px` 为必填。

| 字段 | 含义 / 默认值 |
| --- | --- |
| `name` | 非空模板名称，不可重复 |
| `width_px`, `height_px` | 输出宽高，整数，1–30000；总像素不超过一亿 |
| `background` | 旧模板字段，保留但不自动应用；颜色通过独立「背景色」功能设置 |

模板尺寸在裁剪页只读，修改后按 F5 加载，仅影响下一次应用裁剪。「允许缩放」默认不勾选，此时裁剪框按模板像素固定大小、仅可移动，不进行放大或缩小；裁剪区域无法满足目标像素时，点击「应用」会弹窗报错并保留当前图片与撤销记录。勾选后可调整取景范围，应用时缩放为模板像素；放大可能模糊，缩小会丢失细节。底部「当前」、编辑画布与保存尺寸保持一致；撤销和重做同时恢复取景及像素调整。格式与画质在「图像压缩」中设置；DPI 沿用原图有效值，缺省为 300。旧的 `max_kb` 字段不再生成或生效，现有配置文件中的该字段作为额外数据保留。原有 `format`、`dpi`、`width_mm`、`height_mm` 字段也不自动覆盖导出设置。进一步删除模板也会保留，不会因为选择颜色或切换主题而补回。

只想保留自由裁剪和按比例裁剪：

```toml
[appearance]
theme = "light"

[crop]
templates = []
```

完整默认示例见 [examples/PhotoCraft.conf](../examples/PhotoCraft.conf)。

## 水印颜色与自定义色槽

```toml
[watermark]
color = "#64748b" # 上次选中的水印文字颜色

[colors]
custom = ["#000000", "#ffffff", "#ef4444", "#3b82f6"]
```

`colors.custom` 对应颜色选择窗口中的自定义色槽，最多 16 项，统一使用 `#RRGGBB`。未填写的色槽使用基础预设色（黑、白、灰、红、橙、黄、绿、蓝、紫等），不会在每次打开窗口时清空。画笔、背景色与水印的颜色窗口共用这些色槽。

在窗口中添加或替换自定义颜色会自动保存，取消选择仍保留已修改的色槽；只有确认颜色才更新水印文字颜色。配置导入、导出、编辑和重置同样涵盖颜色。单纯启动程序不会重写已有文件，旧 TOML 没有这两节时使用默认颜色，首次使用颜色窗口后保存到配置。

## 旧配置与保存方式

不再迁移旧设置。启动时发现原来的 QSettings / INI 格式 `PhotoCraft.conf`，以默认 TOML 配置替换；上一版改名的 `config.toml` 从活动配置目录停用，不读取其中的主题或模板。替换前先保留一份 `retired-日期时间-*` 回退副本，程序不会读取该目录。Windows 旧 Qt 注册表设置不再读取。新版的有效 TOML 不会被重置。

语法错误、字段类型 / 范围错误会显示文件路径与具体原因，用户写错的新版 TOML 不会被自动覆盖，可从菜单编辑或显式重置。

程序内「新增模板」只新增，不覆盖同名模板；保存前重新读取文件，保留其他模板和额外配置键。切换主题、保存模板、修改颜色会重新排版 TOML，手工注释可能被规范化文件头替代。菜单编辑、导入、导出保留原始文本。单纯打开或关闭程序只更新窗口状态，不重写配置。

配置保存先在同目录创建临时文件，成功后替换原文件；写入失败保留原文件。
