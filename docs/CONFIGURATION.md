# Web 服务配置

PhotoCraft Web 复用 `PhotoCraft.conf`，格式为 UTF-8 TOML。Docker 镜像通过 `PHOTOCRAFT_CONFIG_DIR=/data` 读取，Compose 用命名卷持久保存该目录。

源码运行时可自行设置 `PHOTOCRAFT_CONFIG_DIR`；默认目录为 Linux 的 `~/.config/PhotoCraft` 或 Windows 的 `%APPDATA%\PhotoCraft`。

## 管理员设置

网页不提供菜单、配置编辑、导入、导出、重置或新增模板。`/api/config`、`/api/config/reset`、`/api/preferences` 和 `/api/templates` 接口均已移除；用户通过自行发送 HTTP 请求也无法调整服务配置。`/api/bootstrap` 只公开渲染页面所需的预设值，不返回配置原文、文件路径或配置错误详情。

部署管理员在持久卷中编辑 `PhotoCraft.conf` 后重启服务。无效配置不会从网页修复，服务使用默认值并在容器日志中记录错误，管理员应修正配置再重启。图片操作及选色不会写入服务配置。浏览器主题仅保存在本机 localStorage。

## 裁剪模板

每个 `[[crop.templates]]` 对应一个模板，可删除、重排或修改。自由裁剪和按比例裁剪始终保留；按比例默认 16:9，可手动修改。

```toml
[appearance]
theme = "light"

[watermark]
color = "#64748b"

[colors]
custom = ["#000000", "#ffffff", "#64748b", "#ef4444", "#f97316", "#f59e0b", "#eab308", "#84cc16", "#22c55e", "#14b8a6", "#06b6d4", "#3b82f6", "#6366f1", "#8b5cf6", "#d946ef", "#ec4899"]

[[crop.templates]]
name = "报名照片"
width_px = 320
height_px = 480
```

只保留自由裁剪和按比例裁剪：

```toml
[crop]
templates = []
```

网页中模板像素只读，规格由管理员在配置文件中设置。默认不允许缩放：按模板像素固定取景框，仅可移动；像素不足时应用会报错。勾选「允许缩放」后可调整取景范围，并缩放到模板像素。

旧字段 `format`、`dpi`、`width_mm`、`height_mm` 可保留，但不覆盖压缩或保存设置。`max_kb` 不生效。图像压缩始终保持已经应用的图片尺寸。

## 会话和资源限制

通过容器环境变量设置：

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `PHOTOCRAFT_CONFIG_DIR` | 镜像内 `/data` | 持久配置目录 |
| `PHOTOCRAFT_MAX_UPLOAD_MB` | `40` | 单个上传文件大小上限，单位 MiB |
| `PHOTOCRAFT_MAX_PIXELS` | `24000000` | 源图片及操作结果的像素总数上限 |
| `PHOTOCRAFT_MAX_SESSIONS` | `4` | 同时保留的编辑会话数 |
| `PHOTOCRAFT_SESSION_TTL` | `900` | 会话闲置过期时间，秒（15 分钟） |
| `PHOTOCRAFT_HISTORY_MB` | `128` | 每个会话撤销缓存预算，单位 MiB，至少保留一步撤销 |

会话只在一个 Python 进程的内存中，部署时保持 **1 个 worker**。不同浏览器页面使用随机会话 ID；不要在没有会话路由的多个独立实例之间随机分配同一会话的请求。

网页不发送定时保活；只有访问会话的服务端请求才会刷新闲置时间。页面持续打开、仅平移或滚轮缩放不会延长会话，默认闲置 15 分钟过期。过期后页面可能仍显示最后的图像，但无法继续处理或保存，需要重新打开图片，未保存的编辑无法恢复。服务器每分钟回收过期会话，请求时也检查过期状态。刷新或离开页面时，通过 `sendBeacon` 尽力释放会话；断网、崩溃时依靠 TTL 回收。浏览器往返缓存暂存页面时不立即释放，以便后退恢复。重启服务会清空所有图片会话。`state.toml` 仅供旧桌面入口使用，Web 不写入桌面窗口状态。

不同会话的数据独立，但服务没有账号认证、租户归属校验或按租户计费与资源配额，随机会话 ID 不等于多租户鉴权。对外部署需通过代理设置访问控制。

## 字体和颜色

水印字体来自运行后端的机器，不枚举浏览器所在设备的字体。优先通过 Fontconfig 发现字体，也支持从 Linux、Windows、macOS 的系统和用户目录读取 TTF、TTC、OTF。镜像不内置指定字体包；Compose 默认只读挂载宿主机字体目录，可通过 `PHOTOCRAFT_FONTS_DIR` 覆盖。未发现字体时使用 Pillow 默认字体，字符覆盖取决于可用字体。

画笔和水印样式弹窗内提供常用色板、取色器与十六进制输入；压缩中的透明区域填充色使用独立颜色对话框。管理员可通过 `colors.custom` 设置预定义色板（最多 16 项，不足时补齐默认颜色）；用户选色只影响当前页面的编辑参数，不写入共享配置。页面不显示常驻字数计数，水印输入框的悬浮提示注明 50 字限制，超长输入会提示并拒绝。

原 QSettings / INI 配置不会迁移；发现旧格式时先保留回退副本，再生成默认 TOML。有效 TOML 会在服务启动时校验，模板删除和空模板列表会按文件内容生效。

## 协议与缓存生命周期

浏览器通过同源 HTTP API 请求处理结果，没有 WebSocket、后台轮询任务或外部图片服务。上传使用 HTTP 请求体；预览和应用使用 JSON；显示与保存通过 HTTP 获取图片。部署 HTTPS 代理后，网页到代理的请求为 HTTPS。

- 每次预览请求由服务完成处理后返回；全服务最多同时执行 2 个渲染任务，连续滑块输入会在浏览器防抖、合并。
- 每个会话最多保留 2 个完整预览，附带编码结果和最长边 1600 px 的展示缩略图；新增预览淘汰最旧项。
- 「应用」直接复用预览中的完整结果并清空旧预览；撤销与重做也会清空旧预览。下载读取已应用的编码字节，不重新运行图像操作。
- 撤销历史最多 20 步，并受 `PHOTOCRAFT_HISTORY_MB` 预算约束（至少保留一步）。原图、当前图、渲染复用缓存及正在处理的结果也会占用内存，因此此预算不是进程总内存上限。
- 释放或过期会话时，会话持有的当前结果、预览、原图、撤销/重做和渲染缓存一起移除，随后由 Python 回收；无需定期手工清理照片目录。内存分配器可能保留已释放内存供后续请求复用，RSS 不一定立即下降。
- 上传解码用的临时文件在解析完成后删除，图片不会写入配置卷。服务重启会释放全部处理缓存。
