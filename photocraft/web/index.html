使用帮助

开始编辑

  1. 在欢迎页选择图片、拖入图片，或按 Ctrl+O 打开。支持 JPG、PNG、WEBP、BMP、TIFF。
  2. 从左侧选择工具，调整右侧参数。裁剪、背景色、旋转、水印和压缩先预览，点击上方「应用」后生效；增强调整即应用，画笔、马赛克和局部模糊松开后即应用。
  3. 底部「预览」显示正在查看的效果，「当前」显示已应用的结果。点击「保存图片」下载当前结果，未应用的预览不会保存。

操作提示

  • 裁剪时拖动取景框调整位置；自由裁剪可拖动边角或输入像素。模板默认按指定像素裁剪，像素不足时需勾选「允许缩放」；放大可能模糊，缩小会损失细节。
  • 背景色只填充透明区域，不会自动抠图。不透明照片可先用画笔中的橡皮擦擦除背景。
  • 水印整页重复平铺，默认替换已有水印；勾选「允许多重水印」后可叠加。图像压缩只调整编码格式和画质，保持当前像素尺寸。
  • 按住「查看原图」对比，松开恢复编辑视图；「1:1」按原像素显示，适应窗口按钮可完整显示图片。

快捷键

macOS 将 Ctrl 换为 ⌘ Command。输入文字时，撤销优先作用于文字。

操作 按键
打开图片 Ctrl + O
保存当前结果 Ctrl + S
撤销 Ctrl + Z
重做 Ctrl + Shift + Z
适应窗口 Ctrl + 0
平移画布 空格 + 拖动
缩放画布 鼠标滚轮
关闭弹窗 Esc
